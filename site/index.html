Wood Cutting Optimizer
使い方 プレイグラウンド GitHub

木材カットを、無駄なく・安く。

Wood Cutting Optimizer は、角材（1D）と合板（2D）から必要な部材を切り出すカットプランを計算するライブラリです。 鋸刃の厚み・ギロチンカット・木目・端材を考慮し、購入費用が最小になる原材の組み合わせを選びます。 TypeScript / Python / Rust（WebAssembly）の3実装が、同じ入力に対して同じ結果を返します。

ブラウザで試す → GitHub リポジトリ

特徴

鋸刃の厚み（kerf）

カットごとに刃の厚みぶんの材料が失われることを考慮し、部材が寸法不足になりません。

ギロチンカット

パネルソーや丸ノコで実際に切れる「端から端まで」のカットだけで構成し、切断順も出力します。

木目の向き

部材ごとに回転の可否・木目方向を指定でき、原板の木目と揃うように配置します。

端材の判定

指定サイズ以上の余りは「再利用できる端材」、それ未満は廃材として区別します。

費用の最小化

サイズ・価格の異なる原材が混在していても、総費用が最小になる組み合わせを選びます。

購入計画

原材の数量を「無制限」にすると、必要な枚数・本数と費用を購入リストとして出力します。

端の切り落とし

傷んだ工場出荷時の端や、割れた木口を先に落としてから配置できます。

SVG カット図面

計算結果を、そのまま印刷して使えるカット図面（SVG）として出力します。

依存ゼロ・4実装

外部ライブラリに依存せず、TypeScript・Python・Rust・WebAssembly で同一の結果を返します。

出力されるカット図面の例

茶色が部材、緑の破線が再利用できる端材、灰色が廃材・刃厚ぶん、赤線がカット線です。

使い方

入力は JSON（または同じ構造のオブジェクト）で、どの言語でも共通です。 下の例は、長さ 1820mm の角材（数量無制限）から、800mm の脚を4本切り出すための計算です。

TypeScript / JavaScript

import { optimize, renderSvg } from 'wood-cutting-optimizer';

const input = {
  dimension: '1D',
  kerf: 3,                                   // 鋸刃の厚み (mm)
  stocks: [{ id: '2x4-6ft', length: 1820, quantity: 'unlimited', cost: 400 }],
  parts: [{ id: 'leg', name: '脚', length: 800, quantity: 4 }],
} as const;

const result = optimize(input);
console.log(result.summary.stock_count_used);  // 2（本）
console.log(result.summary.stock_usage);       // [{ stock_id: '2x4-6ft', quantity: 2, cost: 800 }]
const svg = renderSvg(result, input);          // SVG カット図面

Python

from wood_cutting_optimizer import optimize, render_svg

data = {
    "dimension": "1D",
    "kerf": 3,
    "stocks": [{"id": "2x4-6ft", "length": 1820, "quantity": "unlimited", "cost": 400}],
    "parts": [{"id": "leg", "name": "脚", "length": 800, "quantity": 4}],
}

result = optimize(data)
print(result.summary.stock_count_used)   # 2
svg = render_svg(result, data)

Rust

use wood_cutting_optimizer::{json, optimize, render_svg};

let input = json::parse(&std::fs::read_to_string("input.json")?)?;
let result = optimize(&input)?;            // Err("Invalid input: ...") for invalid input
println!("{}", result.to_value().to_pretty_string());
let svg = render_svg(&result, Some(&input));

入力項目

項目説明
dimension"1D"（角材などの棒材）または "2D"（合板などの板材）
kerf鋸刃の厚み（mm）。省略時 0
min_remnant_size再利用できる端材とみなす最小サイズ。1D は { length }、2D は { width, height }
stocks[]原材。id、寸法（1D: length / 2D: width・height）、quantity（整数または "unlimited"）、cost（単価）、trim（端の切り落とし幅）、2D は grain（木目: none / length / width）
parts[]部材。id、name、寸法、quantity、2D は can_rotate（回転可否、既定 true）と grain

id は一覧内で重複できません。仕様に反する入力は Invalid input: ... のエラーになります。 完全な仕様は specification/schema.json を参照してください。

出力の要点

項目説明
summary.yield_rate歩留まり（使用原材に占める部材の割合、0〜1）
summary.stock_count_used使用した原材の数
summary.stock_usage購入リスト。原材ごとの quantity と cost（単価 × 数量）
summary.total_*_measure原材・部材・廃材・端材の合計面積（1D は長さ）。部材 + 廃材 + 端材 = 原材
stocks[].placements各部材の位置（x, y）・寸法・回転の有無
stocks[].cutsカット線（位置・長さ・刃厚）と切断順 step
stocks[].remnants / waste再利用できる端材 / 廃材の領域
unplaced_parts原材が足りないなどで配置できなかった部材

計算方法

複数の並べ方・配置先の選び方・カット方向・原材の選び方を組み合わせて貪欲法を実行し、 「未配置が少ない → 総費用が安い → 使用数が少ない → 端材が多い → カット数が少ない」の順で最良の結果を採用します。 2D で部材が200個以下の場合は、原材を1枚ずつ最適に埋めていく方法も試します。 詳しくは README を参照してください。
